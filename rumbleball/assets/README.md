# Visuel d’arène

`arena-banner.webp` : illustration générée avec l’outil intégré **imagegen**, le 16 octobre 2026. Image source conservée dans les images générées de Codex ; export web en 1536 × 512, WebP qualité 85. Aucun texte n’est incrusté : le titre et les informations du jeu restent en HTML. Les écussons, le terrain et les pions sont dessinés dans `../visuals.mjs`.

Prompt final utilisé :

```text
Use case: stylized-concept.
Asset type: wide illustrated banner/background for an existing browser game, Rumbleball, a brutal cyberpunk contact-sport team manager.
Primary request: original cyberpunk blood-sport arena key art, gritty hand-painted premium videogame concept art, dramatic physical sports atmosphere rather than generic neon city.
Scene/backdrop: a covered industrial cage stadium at night, scarred steel, concrete, caged crowd, harsh overhead floodlights and a hint of damp haze. In the right half of the image, two powerful adult athletes in battered futuristic contact-sport armour confront each other across a small metallic ball. One athlete has faded turquoise armour and a visible mechanical arm, the opponent rust-orange armour, hard helmet and heavy shoulder pads. They look like athletes, no guns, no weapons.
Composition/framing: very wide landscape, approximately 3:1. Athletes and ball entirely in the rightmost 55%, shown from knees upward with readable large silhouettes; leftmost 45% is a dark quiet stadium wall and shadowy negative space for real HTML title text to be overlaid. Wide shot with room around heads. Do not draw UI panels or lettering.
Lighting/mood: tense pre-match energy, directional dirty amber floodlight, restrained turquoise reflections. Strong sculptural light, analog painted texture and realistic material weight.
Color palette: charcoal, aged ivory, desaturated teal, rust orange, tiny lime accents. No purple or magenta.
Constraints: no text, no typography, no logos, no watermarks, no interface, no gore, no recognizable existing franchise characters. Opaque background. This is a production art asset, not a website mockup.
```
